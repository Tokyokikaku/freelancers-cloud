# ハードAIナビ 運用ルール

コンシューマー向けハードAI（AIペット・家庭用ロボット・AIガジェット・個人向け小型ヒューマノイド等）を紹介するアフィリエイトメディア。
生成は `node build.mjs`（依存ゼロ。npmレジストリが使えない環境でも動く）。記事は `content/articles/*.md`。

## 記事の絶対ルール（自動執筆の事故防止）

1. **出典なしの事実は書かない。** 価格・発売日・仕様は、メーカー公式かプレスリリースを WebFetch で開いて確認した値のみ。検索結果のスニペットだけで書かない。
2. **価格には確認日を入れる。** 冒頭の注記に「価格の確認日：YYYY年M月D日」。本文の価格は出典リンクを付ける。
3. **確認できなかった項目は「未確認」と書く。** 推測で埋めない。出典同士が食い違う値は使わず、片方を採るなら理由を書く。
4. **実機を使っていない。** 「使ってみた」「触った感想」「口コミ」風の文章、架空のレビュー・評価点を書かない。使用感を推測で述べない。
5. **PR表示は自動挿入される**（テンプレート）。記事側で消さない。アフィリエイトリンクの報酬で順位・評価を変えない。
6. **医療・効果の断定、「No.1」「最安」等の根拠なき最上級を書かない。**
7. 値上げ・販売終了など、日付で状況が変わる情報は、日付を表に入れて明記する。
8. frontmatter 必須: title / description / date / updated / sources（`category` は任意：AIペット / 人型ロボット / 購入ガイド）。本文にはURLつき出典を入れる（ビルドが検査する）。

## アフィリエイトリンク

`site.config.json` の `amazonTag` / `rakutenId` を設定後、商品リンクに付与する。未設定の間は公式リンクのみ。リンクには `rel="nofollow"` を付ける（変換器が自動付与）。

## 更新

価格は変動する。既存記事は月1回、公式ページで再確認し、`updated` と本文の確認日を更新する。
