## 結論：27,500円。カード型の本体で録音し、文字起こしと要約までAIに任せられる

PLAUD NOTE（プラウド ノート）は、クレジットカード大のAIボイスレコーダーです。Plaud Japan公式ストアでの価格は27,500円（税込）で、カラーはブラック・シルバー・スターライトの3色です。販売状況は、公式ストアの商品データ（products.json、商品ページの.js）で3色とも購入可能と表示されていました（2026年10月5日確認）。

特徴は、薄さ2.99mm・重さ30gの本体を、付属のMagSafe対応ケースに入れてスマートフォンの背面に装着できることです。通話の録音にも、机に置いた対面の会議の録音にも使えます。録音データは文字起こしされ、AIが要約します。購入すると、毎月300分までの文字起こしを無料のStarterプランで利用できるため、まず月額料金なしで使い始められます。

## できること・仕様（Plaud公式の説明）

### 本体の仕様

公式の製品仕様は次のとおりです。

| 項目 | 内容 |
| --- | --- |
| サイズ | 85.6×54.1×2.99mm |
| 重さ | 30g |
| バッテリー | 400mAh（フル充電時間は約2時間） |
| 連続録音 | 最大30時間（スタンバイは60日間） |
| ストレージ | 64GB |
| ファイル転送 | BLE／Wi-Fi |
| マイク | MEMS×2、VPU×1 |

| 同梱品 | MagSafe対応ケース、マグネットリング、充電ケーブル（Starterプランの文字起こし月300分付き） |

操作は物理ボタンです。長押しで録音を開始し、短押しで「ハイライト」を記録できます。ハイライトは、会話の重要な瞬間をAIに知らせる機能で、要約に反映されると説明されています。

### 2つの録音モード

- **対面録音**：周囲の音声を録音します。会議、ボイスメモ、インタビュー、講義、診察など、対面の会話向けです。
- **通話録音**：スマートフォンの音声を、相手の声も含めて録音します。本体のVPUセンサーがスマホからの音声を直接拾う仕組みのため、通話録音のときは本体をスマホ背面に装着しておく必要があります。

### AIによる文字起こしと要約（Plaud Intelligence）

- 日本語を含む112言語の文字起こしに対応します。発言者ごとのラベル（話者ラベル）、言語と話者の自動検知、自動フォーマット機能に対応します。
- 医療・法律・金融など10種類以上の用語集が内蔵されており、専門用語を優先して文字起こしする「カスタム用語」を使えます。
- 10,000種類以上の要約テンプレート、マインドマップによる整理に対応します。1つの会話を、営業向けのアクション項目、管理者向けのインサイトなど、役割に応じた要約にできると説明されています。
- 録音のほか、テキスト入力と画像入力を組み合わせて文脈を足せる「マルチモーダル入力」に対応します。
- 録音の内容に質問できる「Ask Plaud」があり、回答は音声の元の箇所まで遡って確認できると説明されています。
- 公式の製品ページには、Plaud Intelligenceは最先端のAIモデル（GPT-5.5、Claude Sonnet 4.6、Gemini 3.1 Proを含む）で開発されていると記載されています。
- スマホアプリ（Plaud Mobile App）、Web版（Plaud Web）、パソコン用のPlaud Desktopで録音と文字起こしを確認できます。Plaud Desktopを使うと、オンライン会議の録音にも対応すると説明されています。

本体を購入すると、無料のStarterプランとして毎月300分までの文字起こしを利用できます。それ以上使う場合は、AIプランを追加します。公式ストアのプラン料金は次のとおりです（いずれも税込、2026年10月5日確認）。

| Unlimited | 40,000円／年（月あたり約3,333円相当） | 無制限（1日につき最大24時間） |

月あたりの金額は、年額を12で割った当サイトの計算です。公式のプラン表の表示は年額です。

- Unlimitedプランは、通常の利用範囲で無制限とされ、著しく過度な利用が確認された場合は利用制限を行う場合がある、と公式に記載されています。
- Proプランの月1,200分を使い切った場合は、文字起こしパッケージを追加で購入できます。Proプランの分数が先に使われ、使い切ると次の月にリセットされるまでパッケージが使われる、と説明されています。
- 公式ストアで購入したプランやパッケージは、コードを有効化していない場合に限り、購入日から30日以内なら返金対応が可能です。有効化後は返金の対象外と記載されています。
- 本体とプランのセット商品もあります。Plaud Note＆年間プロプランのセットは44,300円、Plaud Note＆年間無制限プランのセットは67,500円です（公式ストアの商品データ）。
