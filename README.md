# 外注ドットコム LP

静的HTML/CSSで作ったランディングページです。ビルド不要で、Vercel にそのままデプロイできます。

## ディレクトリ構成

```
.
├── public/                  # 公開されるファイル一式（Vercelの出力ディレクトリ）
│   ├── index.html
│   ├── styles.css
│   ├── main.js              # スマホ・タブレット用メニューの開閉のみ
│   └── assets/              # 画像
├── vercel.json              # Vercel設定（出力先・キャッシュ・セキュリティヘッダー）
└── README.md
```

`public/` 以外のファイル（README など）は公開されません。

## ローカルで確認

```bash
npx serve public
# → http://localhost:3000
```

Vercel CLI を使う場合は `npx vercel dev` でも確認できます。

## Vercel へのデプロイ

1. Vercel の「Add New… → Project」からこの GitHub リポジトリを Import
2. 設定はすべてデフォルトのままで「Deploy」
   - Framework Preset: `Other`
   - Build Command: なし
   - Output Directory: `public`（`vercel.json` で指定済み）

以降は `main` ブランチへの push で本番、それ以外のブランチ／PR はプレビュー環境に自動デプロイされます。

## レスポンシブ対応

デザイン・文言・画像配置は元の静的LPのまま、画面幅に応じて以下のように調整しています。

| 画面幅 | レイアウト |
| --- | --- |
| 1181px〜 | PCレイアウト（元デザインそのまま） |
| 981〜1180px | PCレイアウトのまま、余白・文字サイズを少し詰めて折り返し崩れを防止 |
| 641〜980px | タブレット：1カラム。ナビはハンバーガーメニューに格納 |
| 〜640px | スマホ：ヘッダーのボタンもメニュー内に格納。ヒーローのバッジ位置などを調整 |

主な対応内容:

- スマホ・タブレットのハンバーガーメニュー（リンクをタップ／メニュー外をタップ／Esc で閉じる）
- 固定ヘッダーにアンカー先の見出しが隠れないようにスクロール位置を調整
- 見出しなどが「と、」「す」「を」のように1〜2文字だけ次の行に落ちないよう、`<wbr>` で文節単位の改行に制御
- メインコピーは1行目「優秀なフリーランスと、」が途中で折り返さないよう、カラム幅に合わせて文字サイズを自動調整
- FAQ に開閉アイコンを追加（Safari で標準の三角マーカーが出ないように統一）
- 画像の軽量化：ヒーロー画像（1.5MB → WebP 124KB／スマホ用 43KB）、PM画像（2.1MB → WebP 113KB）。WebP 非対応ブラウザ向けに PNG も同梱
- 画像に幅・高さを指定し、読み込み時のレイアウトずれを防止。ファーストビュー以外の画像は遅延読み込み

### 改行位置を変えたいとき

見出しなどの改行は `<wbr>`（ここで改行してよい位置）で制御しています。文言を変更する場合は、改行させたい区切りに `<wbr>` を入れてください。`<br>` は常に改行、`<br class="desktop-only">` は1行に収まる幅があるとき（1181px以上、641〜980px）のみ改行します。
