# 外注ドットコム LP

静的HTML/CSSで作ったランディングページです。ビルド不要で、Vercel にそのままデプロイできます。

## ディレクトリ構成

```
.
├── public/                  # 公開されるファイル一式（Vercelの出力ディレクトリ）
│   ├── index.html
│   ├── styles.css
│   ├── main.js              # スマホ・タブレット用メニューの開閉のみ
│   └── assets/              # 画像
├── api/                     # サーバレス関数（/slide 用、お問い合わせフォーム用）
├── docs/                    # Google Apps Script（お問い合わせの受け口）
├── vercel.json              # Vercel設定（出力先・キャッシュ・セキュリティヘッダー）
└── README.md
```

`public/` 以外のファイル（README など）は公開されません。

## ローカルで確認

```bash
npx serve public
# → http://localhost:3000
```

Vercel CLI を使う場合は `npx vercel dev` でも確認できます。

## Vercel へのデプロイ

1. Vercel の「Add New… → Project」からこの GitHub リポジトリを Import
2. 設定はすべてデフォルトのままで「Deploy」
   - Framework Preset: `Other`
   - Build Command: なし
   - Output Directory: `public`（`vercel.json` で指定済み）

以降は `main` ブランチへの push で本番、それ以外のブランチ／PR はプレビュー環境に自動デプロイされます。

## コンサルスライドメーカー（`/slide`）

素材（打合せの文字起こしなど）を貼ると、AIが「設計図 → HTMLスライド」の順にスライドを作る社内向けツールです。プロンプトは、うちた（[@uchita_success](https://x.com/uchita_success)）さんの記事 [うちた式コンサルスライドメーカー](https://note.com/uchita_success/n/na5babdc58b0e) で無料公開されているものを、そのまま `api/_prompt.js` に入れています（記事のフォーム項目だけ画面の入力欄に置き換え）。

```
api/generate.js      # Claude API を呼ぶ Vercel サーバレス関数（ストリーミング）
api/_prompt.js       # 記事のプロンプト＋この画面向けの運用ルール
public/slide/        # 画面（index.html / app.js / style.css）
```

### 使い方

1. 素材を貼って「設計図を作る」。ヘッド（見出し）を縦に読んで筋が通るか確認する
2. 直したいときは「修正指示」に書いて「設計図を直す」。質問が返ってきたら回答もここに書く
3. OKなら「この設計図でHTMLを作る」。プレビュー、HTML保存、PDF（印刷）ができる

pptx出力は未対応です（記事ではコードを実行できるAIでpython-pptxを使う方式）。HTMLを保存して、そのまま使うか、Claude Code などに渡して変換してください。

### 環境変数（Vercel の Settings → Environment Variables）

| 名前 | 必須 | 内容 |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | はい | Claude API のキー |
| `ACCESS_CODE` | はい | 画面で入力する合言葉。未設定だとAPIは動きません（APIキーの不正利用を防ぐため） |
| `ANTHROPIC_MODEL` | いいえ | 既定は `claude-sonnet-5-5` |
| `MAX_OUTPUT_TOKENS` | いいえ | 既定は `32000` |

ローカルで試すときは `npx vercel dev`（`.env` に上記を書く。`.env` は git 管理外）。HTML生成は長時間かかるため、`vercel.json` で関数の最長実行時間を300秒にしています（プランによっては上限が下がります）。

文字起こしには先方の情報が入ります。AIに渡してよい範囲は、会社のルールと契約に従ってください。

## レスポンシブ対応

デザイン・文言・画像配置は元の静的LPのまま、画面幅に応じて以下のように調整しています。

| 画面幅 | レイアウト |
| --- | --- |
| 1181px〜 | PCレイアウト（元デザインそのまま） |
| 981〜1180px | PCレイアウトのまま、余白・文字サイズを少し詰めて折り返し崩れを防止 |
| 641〜980px | タブレット：1カラム。ナビはハンバーガーメニューに格納 |
| 〜640px | スマホ：ヘッダーのボタンもメニュー内に格納。ヒーローのバッジ位置などを調整 |

主な対応内容:

- スマホ・タブレットのハンバーガーメニュー（リンクをタップ／メニュー外をタップ／Esc で閉じる）
- 固定ヘッダーにアンカー先の見出しが隠れないようにスクロール位置を調整
- 見出しなどが「と、」「す」「を」のように1〜2文字だけ次の行に落ちないよう、`<wbr>` で文節単位の改行に制御
- メインコピーは1行目「優秀なフリーランスと、」が途中で折り返さないよう、カラム幅に合わせて文字サイズを自動調整
- FAQ に開閉アイコンを追加（Safari で標準の三角マーカーが出ないように統一）
- 画像の軽量化：ヒーロー画像（1.5MB → WebP 124KB／スマホ用 43KB）、PM画像（2.1MB → WebP 113KB）。WebP 非対応ブラウザ向けに PNG も同梱
- 画像に幅・高さを指定し、読み込み時のレイアウトずれを防止。ファーストビュー以外の画像は遅延読み込み

### 改行位置を変えたいとき

見出しなどの改行は `<wbr>`（ここで改行してよい位置）で制御しています。文言を変更する場合は、改行させたい区切りに `<wbr>` を入れてください。`<br>` は常に改行、`<br class="desktop-only">` は1行に収まる幅があるとき（1181px以上、641〜980px）のみ改行します。

## お問い合わせフォーム

ページ下部のフォームから送信すると、**Google スプレッドシートに1行追記**され、**info@tyokikaku.co.jp にメールが届きます**（メールの返信先は問い合わせ者のアドレス）。

```
フォーム → api/contact.js（入力チェック） → Google Apps Script → スプレッドシート + メール
```

```
api/contact.js         # 入力検証して GAS に転送する Vercel 関数
docs/contact-gas.gs    # スプレッドシート追記＋メール送信の Apps Script
```

### セットアップ（初回のみ）

1. 記録用の Google スプレッドシートを新規作成（info@tyokikaku.co.jp のアカウント推奨。メールはこのアカウントから送られます）
2. 「拡張機能 → Apps Script」を開き、`docs/contact-gas.gs` の中身を貼り付けて保存
3. 「プロジェクトの設定 → スクリプト プロパティ」に `SECRET` を追加（推測されにくい長いランダム文字列）
4. 「デプロイ → 新しいデプロイ → ウェブアプリ」。実行ユーザー＝自分、アクセスできるユーザー＝全員。初回は権限の承認が必要（スプレッドシートとメール送信）。発行された `…/exec` の URL を控える
5. Vercel の Settings → Environment Variables に登録して再デプロイ

| 名前 | 内容 |
| --- | --- |
| `CONTACT_WEBHOOK_URL` | 手順4の `…/exec` の URL |
| `CONTACT_WEBHOOK_SECRET` | 手順3の `SECRET` と同じ値 |

「問い合わせ」シートは初回の送信時に自動で作られます。スクリプトを修正したときは「デプロイを管理」から新バージョンで更新してください。

注意:

- GAS のメール送信には1日の上限があります（無料の Gmail で約100通、Workspace で約1,500通）。通常の問い合わせ量なら問題ありません。
- スパム対策は、画面に出ない入力欄（ハニーポット）のみです。迷惑投稿が増えたら reCAPTCHA / Turnstile の導入を検討してください。
- 環境変数が未設定のときは、フォームがエラーを表示して「メールでご連絡ください」と案内します。
- 送信テストは `npx vercel dev`（`.env` に上記2つを記載）で確認できます。

ヘッダーなどの「まずは相談する」ボタンは、このフォームの位置へスクロールします。
