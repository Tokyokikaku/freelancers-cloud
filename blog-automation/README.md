# スプレッドシート → Wix ブログ自動投稿

Google スプレッドシートの記事 (Markdown) を、Wix Blog API で自動投稿する Google Apps Script です。
サーバー不要で、スクリプトはスプレッドシートに紐づけて動かします。

## 流れ

1. AI が行を追加する (ステータス: `下書き`)
2. 人が内容を確認し、ステータスを **`承認済み`** に変える
3. スクリプト (1時間ごと) が `承認済み` の行を Wix に投稿する
4. ステータスが `Wix下書き済み` (既定) または `公開済み` に変わり、記事ID・URL・投稿日時が書き戻される
5. 失敗時はステータスが `エラー` になり、原因が「エラー」列に入る。直したら `承認済み` に戻すと再試行する

シートの右端に「Wix記事ID / 投稿URL / 投稿日時 / エラー」列が自動で追加されます。

## 本文の扱い

- 先頭の `# タイトル` は削除します (Wix のタイトル欄と重複するため)
- `> 📷 画像候補：…` の引用ブロックは制作メモとして削除します。画像は Wix 側で手動で入れてください
- 残りは Wix の Convert To Ricos Document API (Markdown → リッチコンテンツ) で変換します

## セットアップ

1. **Wix の API キーを発行する**: Wix アカウント設定 → API キー。対象サイトを限定し、権限は「Manage Blog」「Manage Ricos Document」と、手順4の間だけ「Read Members」を付けます
2. **サイトIDを調べる**: 管理画面 (ダッシュボード) を開いたときの URL に含まれる UUID です
3. スプレッドシートの 拡張機能 → Apps Script を開き、`Code.gs` の中身を貼り付けて保存し、プロジェクトの設定 → スクリプト プロパティに `WIX_API_KEY` と `WIX_SITE_ID` を追加
4. **投稿者の member ID を調べる**: `listMembers` を実行すると、ログに `ID | メールアドレス | ニックネーム | 公開設定` が出ます。投稿者にするメンバーの ID を控え、スクリプト プロパティ `WIX_MEMBER_ID` に入れます。終わったら API キーから「Read Members」権限を外します
5. 必要なら `PUBLISH` = `true` を追加 (即公開。未設定なら Wix の下書き止まり)
6. まず `postApprovedArticles` を手動実行して権限を承認し、1件だけ `承認済み` にして動作を確認
7. 問題なければ `installTrigger` を1回実行 (以後1時間ごとに自動実行)

API キーはシートやリポジトリに書かず、必ずスクリプト プロパティに入れてください。

## 初回に確認すること

Wix の API 仕様は公式ドキュメントで確認済みですが、実際のサイトでの呼び出しはまだ試していません。
最初は `PUBLISH` を未設定のまま下書きを作り、Wix のエディタで次を見てください。

- 見出し (`##`) や太字、引用が崩れていないか (崩れる場合は `CONFIG.RICOS_PLUGINS` を調整)
- カテゴリは未設定です (「業界・カテゴリ」列と Wix カテゴリの対応づけは未実装)
