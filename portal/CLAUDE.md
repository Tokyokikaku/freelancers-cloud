# portal（成果報酬ナビ）作業ルール

- **サイトの仕様・文言を変更したら、プライバシーポリシー（`src/app/(site)/privacy/page.tsx`）と運営情報（`src/app/(site)/about/page.tsx`）の内容も、変更に合わせて更新する。**
  対象の例: 取得する入力項目の追加・削除、第三者（サービス提供会社・外部API・計測ツール）への提供や外部送信の変更、同意の取り方の変更。
  同意文言を変えたときは `src/lib/lead-options.ts` の `CONSENT_VERSION` も更新する。
- プライバシーポリシーは「ひな形」の扱い（公開前に法務確認）。ただし内容は実装と常に一致させる。
- 未提携の企業を提携しているように見せない。禁止表現は `npm run check:terms` で検査する。
